Optics Bench: a live catalog of Canvas UI

Optics Bench runs all 33 Canvas UI shader effects over one real, interactive HTML page. The buttons still click and the input still types while the interface is being shattered, rippled or dithered. Nothing on the bench is a screenshot.

Chrome has an experimental html-in-canvas API that lets a shader sample live DOM, not a screenshot and not an iframe. Docs show effects one at a time; this page runs the same interface through every one of them, which is the fastest way to work out which effect is right for what.

Bench

Pick any of 28 Canvas UI lenses and apply it to a live specimen UI: a console, a storefront or an editorial page. Press F to apply the current effect to the entire page, and use the bracket keys to cycle through effects.

Objects

The five three.js renderers, all pointed at the same SVG. One SVG, five materials, no 3D pipeline and no flag.

Built here

Six effects (mosaic, ordered dither, ASCII, tear, ripple and CRT) and the engine under them, written from scratch against the raw html-in-canvas API. MIT licensed, in the repo, no dependency.

Uses

All 33 effects, each with the use case it is genuinely best at. Eighteen of them need Chrome's html-in-canvas flag; the other fifteen run in any modern browser.
